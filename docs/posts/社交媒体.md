# 欢迎来到我的写作空间

这是我的第一篇文章。在这个写作文件夹中，你可以：

- 使用 Markdown 语法写作
- 在 `docs/posts/` 目录下创建新的 `.md` 文件
- 自动生成目录和导航

## 如何添加新文章

在 `docs/posts/` 目录下创建新的 `.md` 文件即可自动出现在网站中。

```markdown
---
title: 文章标题
date: 2024-01-01
---

# 正文内容
```

## 下一步

1. 运行 `npm install` 安装依赖
2. 运行 `npm run dev` 预览网站
3. 修改 `docs/.vitepress/config.mts` 定制网站配置
