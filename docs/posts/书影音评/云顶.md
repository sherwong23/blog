# 云顶技术总结

## 节奏
云顶之弈的核心逻辑是节奏，无论是海克斯，经济，阵容，装备，站位等等都基于节奏。最基础的节奏是延续连胜或连败。比如开局嫖到了二星质量，大概率打出连胜，那就要合装备，就要拉等级，打出压制，海克斯要选即使战力（或装备），或者即使经济拉等级。而过度质量，装备合成也同时影响了定阵，整局游戏便有了大致思路。连败则是拿延迟战力，倒三角站位，等完美装备等延迟型操作。

更进一步则是对大局的判断，同样是六连胜到了3-2，有些情况可以接受拉7继续打压制，有些则可以拿前瞻装连败，同理六连败3-2的海克斯有时会选即时提升，稳点血量，有时破釜沉舟再拿个经济冲三星四费或九五。这种判断取决于你对局势的理解，对阵容的熟悉，对当前对局的观察。核心在于3-2海克斯后要选择自己的路了，如果是低费赌狗，那就一定要转连胜，d卡提质量，如果是八四，也要适当拉口保容错。还要对自己的优劣有一定把握，如果判断自己仍是好局，则可以求稳选个平庸海克斯，落点在八四，冰皮或艾欧，如果发现劣势很大，则可选赌的海克斯试图玩到四人组拼多多，千珏等上限，又或者选祖安保一个下线。
