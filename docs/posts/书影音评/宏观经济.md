## 从市场经济循环的三个环节到国内生产总值的三种计算方法
1. 生产法gdp
   所有常住单位在一定时期内生产的全部货物和服务价值超过同期投入的全部非固定资产货物和服务的差额，即所有常住单位的增加值之和
   生产法GDP = 总产出-中间投入
            = 第一产业增加值 + 第二产业增加值 + 第三产业增加值
            = VAl+VA2+VA3

2. 收入法gdp
    所有常住单位在一定时期内创造并分配给常住单位和非常住单位的初次分配收入之和
    收入法GDP = 劳动者报酬 + 生产税净额 + 固定资产折旧 + 企业盈余
    = W + T + D + I

3. 支出法GDP （GDP by expenditure）
    最终使用的货物和服务减去进口货物和服务
    支出法GDP = 居民消费 + 资本形成总额（投资） + 政府消费 + 出口 - 进口（三驾马车）
    = C + I + G + X - Im

劳动和资本可以互相替代
增加工资，降低就业，劳动报酬总额不变
投资占支出比例过大
gdp计算要用市场供求关系决定的市场价格来计算/统计的是竞争性市场所产生的结果
国民幸福的定义会影响gdp统计和经济政策

##
发展初期储蓄》消费 后期消费〉储蓄

发展初期的经济体确实不一定要依靠居民储蓄来投资，政府完全可以通过发债把资金提供给企业，同时让居民保持较高消费；但关键约束在于真实资源：投资需要机器、钢铁、劳动力、能源等，如果经济已经充分就业、居民又把全部产出用于消费，那么政府发债并不能凭空创造这些资源，只会增加需求并可能引发通胀。只有在存在闲置产能和失业时，政府借债支持投资才可以同时提高消费、就业和投资；此外，也可以利用外国资本和进口设备获得国外的真实资源。因此，居民储蓄不是发展的唯一融资方式，但一个经济体必须有一部分当前产出从消费转向投资，才能形成未来的生产能力。
